저장소 파일을 참조하는 방식과는 별개지만, 다른 곳에도 첨부하기 쉽도록 이 크기 안에 맞췄습니다.

## 무엇을 녹화했나요?

- 기준 코드: `acd752f` (2026-09-20 녹화 당시). 앱의 기능 코드는 변경하지 않았습니다.
- Playwright 1.63.0으로 별도 Chrome을 실행하고, 실제 Next.js 화면과 FastAPI·MySQL의 응답을 사용했습니다. API 응답을 성공한 것처럼 가로채거나 대체하지 않았습니다.
- 기존 데이터와 분리한 로컬 시연 DB를 사용했습니다. 가상 계정, 예시 관광지·식당·행사와 시연용 게시글을 준비했습니다. 녹화 후 이 DB와 임시 계정은 정리했습니다.
- 스팟 이미지에는 저장소에 있던 첨성대 일러스트를 사용했습니다. 실제 방문자가 촬영한 사진이나 작성한 후기처럼 소개하지 않았습니다.
- 장소 검색 후 등록, 외부 길찾기 실행, 실제 GPS 방문 인증, 음성 재생, 간편 로그인은 이번 영상의 검증 범위에 포함하지 않습니다.
- 동경이의 아이템 연결과 착장 저장은 미완성 상태여서 완성된 기능으로 시연하지 않았습니다.

## 화면 강조와 파일 변환

실제 앱을 담은 모바일 화면을 QHD 캔버스 안에 배치했습니다. 글꼴과 화면은 녹화 시점에 해당 크기로 렌더링했으며, 작은 GIF를 나중에 QHD로 늘린 방식이 아닙니다.
각 단계의 실제 화면 요소 위치를 기준으로 주변을 어둡게 만드는 스포트라이트, 금색 바운딩 박스, 연결선과 한국어 설명 카드를 겹쳤습니다. 설명은 앱 위에 덧붙인 영상용 안내입니다.

Playwright의 연속 영상 녹화 결과를 FFmpeg로 GIF로 변환했습니다. 최대 초당 10프레임을 기준으로 거의 같은 프레임을 합치되 읽는 시간은 유지했습니다. Gifsicle로 파일을 추가 최적화했으며, 지도 영상에는 작은 색상 차이를 허용하는 압축을 적용했습니다. 화면 크기는 네 편 모두 동일합니다.
중간 영상·캡처·시연용 서버 파일은 저장소에 추가하지 않았습니다.
